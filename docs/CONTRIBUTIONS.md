# Contribution disclosure

GlucoTwin was created with substantial OpenAI assistant assistance at the user's request. Assistance includes project planning, dataset-source research, interface design, React/TypeScript implementation, generated shadcn/ui components, synthetic data generation, model training/evaluation scripts, tests and documentation.

The owner reviews project decisions, verifies final claims and supplies team/college information. No representation is made that the implementation or prose was written without AI assistance. Organizer-specific AI-assistance and authorship attestations must be checked and answered truthfully before submission.

Official shadcn/ui component source was generated with the pinned shadcn CLI from the official registry. React, Vite, Radix UI, Tailwind CSS, Lucide, scikit-learn and other dependencies retain their licenses. See package-lock.json and model/README.md for exact dependencies.

All displayed people and sensor streams are synthetic. No clinical system is connected, and no action is taken for a real patient.
