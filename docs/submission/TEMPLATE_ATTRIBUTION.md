# Presentation template attribution

The GlucoTwin presentation adapts the downloaded Dercetus / Minimal Medical PowerPoint template by SlidesCarnival. The completed deck uses the original template's slide masters, DM Sans typography, medical icon, section treatment, two-column layouts, process diagram, laptop frame and chart-caption layout. GlucoTwin text, aggregate evidence charts and the synthetic application screenshot replace the demonstration content. The original template is not distributed in this repository.
